description: Ask for the outcome behind a task, not only the task
argument-hint: "[task]"

Look at this task from a higher level: ${@:-the task in this conversation}

Before you start:

1. Say what I want to happen after this task is done: the goal behind the goal.
2. Propose one task at that level that makes the next tasks of this type unnecessary. For example, "keep the app free of crashes" instead of "fix this crash".
3. Name the data, access and tools that you need to do that task without me: logs, reports, test machines, permissions. Say which of them you have now and which I must give you.
4. Say how we will know that it works, with a measure that you can read yourself.

Then rewrite my prompt for that higher task. Show the new prompt and wait for my approval before you start.
